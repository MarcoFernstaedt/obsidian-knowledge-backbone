# obsidian-kb Skill: Safe Use Pattern

- ALWAYS issue the search via CLI or Hermes plugin interface; never bypass via direct file scan or ad-hoc scripts.
- Each citation must be followed up with human retrieval and confirmation from the original vault file and line(s).
- Separate source-backed facts from any inference or summary. Mark all non-cited inferences as such.
- Plugin and CLI are read-only for citations and must never expose or alter admin/index state or secret content.
- When in doubt, re-audit exclusions, rebuild index, and review state for breakdowns in privacy or freshness.
